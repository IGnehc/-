# 暗夜村庄 · 狼人杀 V1

## 运行

安装 Node.js 20+。进入项目目录后执行：

```bash
npm install
npm start
```

打开 http://localhost:3000 。同一 Wi-Fi 的设备可以用 `http://电脑局域网IP:3000` 访问（需允许防火墙入站）。

## 联机部署

将整个目录推送到 GitHub 私有仓库。在 Render / Railway 等支持 Node.js WebSocket 的托管服务中创建 Web Service，构建命令 `npm install`，启动命令 `npm start`，服务端监听 `process.env.PORT`。部署后把 HTTPS 地址分享给其他玩家。

## 当前规则

6人：2狼人、1预言家、1女巫、2村民。狼人夜间各自投票，票数相同随机选择目标；预言家每晚查验1人；女巫各有1次救药和毒药，不能同夜使用两瓶；白天轮流发言两轮，随后投票；平票时平票玩家PK发言，所有存活者重新投票，仍平票可继续PK。无票时无人出局。狼人全部出局好人胜；狼人数量达到或超过其他存活玩家数量狼人胜。出局身份仅在游戏结束后公开。掉线真人由AI接管。

## 安全与限制

- 真实身份、查验结果、狼人名单只存于服务器，不发送给其他玩家；AI仅接收自己的角色和可观察记录。
- 当前基础AI为独立规则策略和各自记忆，不调用大模型；策略简单，尚不具备高级自然语言理解。
- 房间和状态仅保存在服务进程内存中，重启后清空；不支持跨实例扩容、重连恢复、用户登录、数据库持久化。
- 房间码不是密码。公开互联网部署建议后续增加鉴权、速率限制、房间过期清理和日志隐私策略。


## V2.0 基础 AI 升级
- 每个 AI 有独立的性格、怀疑分数、发言摘要、公开身份声明与投票记录。
- 预言家 AI 保存私有查验结果；狼人 AI 只利用同伴身份做阵营决策。
- AI 根据已有记忆选择投票目标，生成不同风格的中文发言。
- 无需模型 API Key；这是规则推理 AI，不具备大模型级自然语言理解。
- 部署 Render：将 server.js 更新到 GitHub，Render 自动部署；若未启用自动部署，手动 Deploy latest commit。
- 旧的进行中对局不会迁移，部署后需创建新房间。


## V2.1 联机修复
- 新增房间恢复 token，保存在当前浏览器 localStorage 中；断线重连会尝试恢复大厅座位。
- 大厅断线后保留位置 120 秒，防止网络短断直接删房。
- 分别提示房间不存在、已经开始、已满。
- Render 服务器重启仍会丢失内存房间；需要重新创建房间。
- 游戏开始后断线依旧由 AI 接管，**不支持进行中夺回座位**。
- 请在同一 Render 服务单实例运行；部署新版本前结束旧对局。
- 更新 GitHub 的 server.js 和 public/index.html 两个文件。
